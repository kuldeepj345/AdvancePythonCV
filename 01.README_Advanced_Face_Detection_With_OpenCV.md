# Enhanced Face Detection GUI (with Filters and Recording)

A PyQt5-based desktop application that uses OpenCV to perform real-time face detection with optional visual filters, live statistics, recording, and snapshot functionality.
🧰 Features
    Real-time face detection using Haar cascades.
    Multiple video filters including:
        Grayscale
        Sepia
        Invert
        Blur (intensity-adjustable)
        Edge Detection (Canny)
        Thresholding
    Live FPS display.
    Face count graph (live rolling chart).
    Color picker for customizing face detection box color.
    Filter intensity control.
    Video recording (AVI format).
    Snapshot saving with custom filename support.
    Adjustable frame size (640×480, 800×600, 1280×720).
    Intuitive GUI controls (combo boxes, sliders, buttons).
    Simple menu bar for common actions and help info.

🖥 Requirements
    Python 3.6+
    OpenCV (opencv-python)
    PyQt5
Install dependencies with:
pip install opencv-python pyqt5

🚀 How to Use
    Run the script:
    python face_detection_gui.py
    Controls Overview:
        Frame Size Dropdown – Choose resolution.
        Filter Dropdown – Select from various image filters.
        Intensity Slider – Adjust the strength of some filters.
        Color Picker – Choose color for face detection rectangles.
        Snapshot Input – Type a filename or leave blank for auto-naming.
        Start/Stop Recording – Save video with current settings.
    Menu Bar:
        File:
            Start/Stop Recording
            Save Snapshot
        Help:
            Shows a usage guide.

📦 File Output
    Snapshots saved as .png in the working directory.
    Videos saved as output.avi (20 FPS, XVID codec).
    Filename for snapshots can be user-defined or time-stamped automatically.

📊 Real-Time Stats
    Face Detection Count: Number of faces currently detected.
    FPS Monitor: Frames per second display.
    Face Count Graph: 100-frame rolling graph showing recent detection activity.

🧠 Code Structure
    FaceDetectionApp:
        Main class handling GUI, webcam feed, filtering, statistics, and file IO.
    applyFilter:
        Applies user-selected visual effects to each frame.
    updateFrame:
        Captures frames, applies filters and face detection, updates UI.
    startRecording, stopRecording, saveSnapshot:
        Handle media output.
    pickColor, updateFilter, updateFrameSize, etc.:
        Manage user input changes.

🛑 Exiting
    On window close, camera is released and recording stopped safely.
